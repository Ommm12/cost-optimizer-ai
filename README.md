# 🚀 AI-Powered AWS Cost Optimization System

## 🔥 Overview
Built a full DevOps system that monitors AWS cost, detects anomalies, and visualizes trends using AI-based logic.

## ⚙️ Architecture
GitHub → CI/CD → EC2 → Streamlit Dashboard  
AWS Lambda → Cost Explorer → SNS Alerts → S3 Storage

## 🚀 Features
- Automated cost monitoring (AWS Lambda)
- Email alerts (SNS)
- Cost reports stored in S3
- Live dashboard (Streamlit on EC2)
- CI/CD pipeline (GitHub Actions)
- AI-based anomaly detection
